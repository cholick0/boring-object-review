## The entry

> One star. The tea towel has been damp since 2019, smells faintly of dishwater, and still gets handed to guests like it's fine.

126 characters, one line. The joke comes from how a tea towel really behaves: it never dries, it carries the smell of every wash, and it still gets offered to guests as if that were normal.

## How it works

`main.ts` (Node 22) writes the review to `/output/entry.txt`, after a self-check gate enforces the competition gate: 1–200 characters, a single line, not only white space — plus a byte-for-byte read-back verification of what was written.

```sh
node main.ts
cat /output/entry.txt
```
